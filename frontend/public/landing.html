Automatic Setup & Launch Script (Recommended)

We've created a custom batch script in the root directory of this project called install.bat. It installs all python & npm packages and starts both servers simultaneously.

How to launch:

1

Ensure prerequisites are met

Make sure you have Node.js (v18+) and Python (3.9+) installed.

2

Run the installation script

Double click the script or execute it from PowerShell / Command Prompt:

.\install.bat
3

Access application

The script will automatically configure all packages and open the desktop launcher. Alternatively, navigate directly to http://localhost:5173.

1 Ollama Models Pull

Make sure Ollama is installed and running, then pull the optimization models:

ollama pull nomic-embed-text
ollama pull qwen2.5-coder:7b
2 Python API Backend Setup

Open a terminal in the backend folder to setup dependencies and launch on port 11411:

cd backend && pip install -r requirements.txt
uvicorn app.main:app --reload --port 11411
3 React Vite Frontend Setup

Open another terminal in the frontend folder to install and run the development server:

cd frontend && npm install
npm run dev

* Once both servers are active, open the address below to use the client.
